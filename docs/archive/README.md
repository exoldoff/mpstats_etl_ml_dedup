# Архив документации

Здесь лежат исторические аудиты, старые диагностические отчёты и материалы,
которые полезны как контекст, но не являются главным маршрутом чтения проекта.

Для первого знакомства лучше идти так:

1. `README.md`
2. `docs/JURY_GUIDE.md`
3. `notebooks/README.md`
4. `docs/ARCHITECTURE.md`
5. `docs/ARCHITECTURE_PROGRESS.md`

Архивные файлы можно открывать, когда нужно понять, почему было принято
конкретное инженерное решение или какая проблема уже исследовалась раньше.
